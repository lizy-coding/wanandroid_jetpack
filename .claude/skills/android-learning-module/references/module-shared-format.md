# Shared Output Format

Use this format for all module workflows. If job-market alignment is not requested, mark that section as "Not requested".

- Module: <name>
- Objective: <1-2 lines>
- Project anchors: <paths + what to inspect>
- Key concepts (3-year focus): <bullets>
- Interview focus expansion:
  - Fundamentals: <bullets>
  - Architecture/system: <bullets>
  - Performance/stability: <bullets>
  - Testing/quality: <bullets>
  - Common pitfalls: <bullets>
- Job requirements alignment:
  - Repeated keywords: <bullets>
  - Coverage in project: <bullets>
  - Gaps to close: <bullets>
- Hands-on tasks:
  - <2-4 tasks tied to project files>
- Follow-up prompts:
  - <1-3 questions to confirm depth or choose next module>
